# Ashen World (Пепельный Мир)

Низкополигональный сюжетный шутер с мета-ироничным сюжетом, созданный в рамках челленджа "30 проектов за 30 дней".

## 🛠 Технологии
- **Движок:** Godot 4.3 (Forward+)
- **Язык:** GDScript
- **Стиль:** Low-Poly постапокалипсис (процедурные примитивы и текстуры)

## ✨ Особенности
- Сюжетная кампания из 4 миссий + хаб.
- Экзокостюм (режимы Брони, Скорости и Силы).
- 7 видов оружия (включая миниган и ракетницу).
- Продвинутый ИИ (камекадзе, дроны, снайперы).
- Полноценный интерфейс и настройки в стиле Crysis.

## 🚀 Как запустить
1. Открой проект в Godot 4.3.
2. Нажми F5 для запуска из редактора.
3. Или установи готовую сборку через `AshenWorld_Setup.exe`.
